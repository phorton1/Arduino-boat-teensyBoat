Fusion 360.  The enclosure holds the PCB securely, exposes all connectors, and mounts
to the installation surface.

## Enclosure Files

Print-ready and slicer files are in `docs/3dp/`:

- **teensyBoatBottom.stl** -- main enclosure body
- **teensyBoatTop.stl** -- top cover
- **teensyBoatBottom.3mf** -- slicer project file for the bottom (Bambu/PrusaSlicer)
- **teensyBoatTop.3mf** -- slicer project file for the top
- **teensyBoatBottom_PETG.gcode** -- pre-sliced printer gcode for PETG filament
- **teensyBoatTop_PETG.gcode** -- pre-sliced printer gcode for PETG filament

The Fusion 360 source (`.f3d`) is not currently included in the repository.
